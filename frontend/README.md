# Music Streaming Frontend

Next.js + Tailwind CSS frontend for the Music Streaming Web App portfolio project.

## Tech stack

- Next.js App Router
- TypeScript
- Tailwind CSS

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:3000`.

## Environment

Copy `.env.example` to `.env.local` when connecting the backend API later.

```env
NEXT_PUBLIC_API_URL=http://localhost:5000/api
```

## Check

```bash
npm run lint
npm run build
```
